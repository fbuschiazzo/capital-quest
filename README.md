# Capital Quest

Juego web/PWA de educacion financiera sobre trabajo, inversiones y crecimiento patrimonial.

## Probar localmente

Abrir `index.html` directamente en el navegador.

## Mecanicas actuales

- Monto inicial y efectivo disponible.
- Trabajos con energia mensual.
- Marketplace de inversiones.
- Bonos, acciones, cripto, apartamentos, franquicia y startup.
- Desbloqueos por patrimonio.
- Eventos mensuales, volatilidad e ingresos pasivos.
- Portfolio, progreso de nivel y guardado local.
